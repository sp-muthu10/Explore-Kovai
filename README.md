# Kovai Tourist Guide 🌄

A modern web application that helps tourists explore the best places in **Coimbatore district** with detailed information including history, transport connectivity, crowd levels, nearby attractions, and facilities.

This project provides a clean and user-friendly interface to help travelers plan their visits efficiently.

---

## 🌍 Live Website

Deployed using **Vercel**

Link:
https://your-vercel-link.vercel.app

---

## ✨ Features

* 🔎 Search tourist places
* 🏷 Filter by category (Temple, Nature, Waterfall, Lake, etc.)
* 📊 Crowd level indicators
* 📍 Nearby attractions with distance
* 🕐 Opening and closing timings
* 🚍 Bus connectivity information
* ✈ Nearest airport details
* 🖼 Image gallery for each location
* ⭐ Featured tourist places section
